Что такое API

DataSeeker API отдаёт JSON по одному POST-запросу. Вы передаёте тип поиска и строку запроса — в ответе связанные контакты, профили и метаданные из индекса. Ответы на этой странице синтетические: живой индекс доступен из бота.

Быстрый старт

1
Создайте ключ выше — бесплатно.
2
Отправьте тестовый запрос. Бонус новичка: 1 ₽ = 1 вызов.
3
Пополните пакет, когда баланс обнулится. Пакеты не сгорают.

Ответ и billing

Успешный ответ списывает 1 ₽ и возвращает новый баланс. Поле demo: true значит, что запись синтетическая. В проде это поле отсутствует. 

{
  "ok": true,
  "request_id": "ds_9f3a…",
  "billed": 1.0,
  "balance": 549.0,
  "type": "phone",
  "query": "79991234567",
  "found": true,
  "data": { "names": ["…"], "city": "Москва" }
}
