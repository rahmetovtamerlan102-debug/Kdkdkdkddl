Что такое API

DataSeeker API принимает POST-запрос с JSON. Передаёте Telegram ID — получаете профиль: имя, дата регистрации, группы, подарки. Каждый запрос списывает 1 ₽ с баланса ключа.

Справочник по эндпоинту

// Запрос к API сервиса
POST https://qq-mrl3.onrender.com/api/v1/search
{
  "key":   "dsk_YOUR_KEY",
  "query": "1234567890",
  "type":  "tg_id"
}

// Результат ответа
{
  "ok":              true,
  "query":           "1234567890",
  "type":            "tg_id",
  "sources":         ["Funstat", "Telegram · Подарки"],
  "records_count":   3,
  "gifts_count":     3,
  "text":            "✈️ Telegram · 1234567890\n\n🕐 Регистрация: ...",
  "balance_kopeks":  100,
  "total_searches":  1,
  "today_searches":  1
}

Примеры на языках

Подставьте ключ вместо dsk_YOUR_KEY и TG ID вместо 1234567890.

Batch-запросы

Поиск по массиву Telegram ID за один HTTP-запрос. Экономит время и трафик — обрабатывается до 50 ID за раз. Списание как обычно: 1 ₽ за каждый ID. 

// Batch-запрос
POST https://qq-mrl3.onrender.com/api/v1/search/batch
{
  "key":     "dsk_YOUR_KEY",
  "queries": ["1234567890", "9876543210", "5554443332"],
  "type":    "tg_id"
}

// Результат ответа
{
  "ok": true,
  "count": 3,
  "results": [
    {"query": "1234567890", "ok": true, "text": "✈️ Telegram · ...", "records_count": 3, "gifts_count": 1},
    {"query": "9876543210", "ok": true, "text": "✈️ Telegram · ...", "records_count": 5, "gifts_count": 0},
    {"query": "5554443332", "ok": false, "error": "Not found"}
  ],
  "billed_kopeks":  300,
  "balance_kopeks": 9700,
  "total_searches": 18,
  "today_searches": 6
}

Правила batch

ПРАВИЛОЗНАЧЕНИЕ
Макс. ID за раз50
Списание1 ₽ × количество ID
ДубликатыАвтоматически удаляются
НевалидныеПропускаются (только цифры)
Ошибка одногоНе влияет на остальные

Ответ и billing

ПОЛЕТИПОПИСАНИЕ
okboolУспех запроса
querystringЗначение запроса
typestringТип поиска (tg_id)
sourcesarrayИсточники, отдавшие данные
records_countintКоличество записей в отчёте
gifts_countintСколько подарков найдено
textstringHTML-превью отчёта (как в боте)
balance_kopeksintНовый баланс в копейках (100 = 1 ₽)
total_searchesintВсего запросов по ключу за всё время
today_searchesintЗапросов за сегодня
