Документация API

Базовый URL

API https://qq-mrl3.onrender.com

Создание ключа

# Создать ключ curl -X POST https://qq-mrl3.onrender.com/api/v1/key/create \ -H "Content-Type: application/json"

Проверка ключа

curl -X POST https://qq-mrl3.onrender.com/api/v1/key/info \ -H "Content-Type: application/json" \ -d '{"key":"dsk_твой_ключ"}'

Поиск

curl -X POST https://qq-mrl3.onrender.com/api/v1/search \ -H "Content-Type: application/json" \ -d '{ "key":"dsk_твой_ключ", "query":"пример", "type":"phone" }'

Тело запроса

Поле Тип Описание
key string API-ключ вида dsk_...
query string Значение для поиска
type string Тип поиска
