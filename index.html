Что такое API

DataSeeker API отдаёт JSON по одному POST-запросу. Вы передаёте Telegram ID — в ответе профиль, история ников, группы и подарки. Каждый успешный запрос списывает 1 ₽ с баланса ключа.

Быстрый старт

1
Создайте ключ выше — бесплатно. Новичкам 1 ₽ на тест.
2
Выполните запрос по TG ID. С баланса спишется 1 ₽.
3
Пополните пакет, когда баланс обнулится. Пакеты не сгорают.
