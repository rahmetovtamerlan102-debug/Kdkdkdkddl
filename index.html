Что такое DataSeeker API

DataSeeker API — это HTTP-сервер, который принимает запросы от твоей программы и возвращает структурированные данные: телефон, ФИО, соцсети, Telegram, историю подарков и другое.

Ты создаёшь API-ключ в личном кабинете, вставляешь его в заголовок каждого запроса — и получаешь данные. Каждый поиск списывает 1 ₽ с твоего баланса.

Информация Данные предоставляются из открытых и коммерческих источников. Полнота результата зависит от наличия данных в базах.

Быстрый старт

1. Создай API-ключ

Открой бота @dataseekersearch_bot → Личный кабинет → «Создать API-ключ». Первые 5 ключей — бесплатно.

2. Сделай первый запрос

curl -X POST https://qq-mrl3.onrender.com/api/v1/search \
  -H "X-API-Key: dataseeker_твой_ключ" \
  -H "Content-Type: application/json" \
  -d '{"query": "+77083706944", "type": "phone"}'

3. Получи ответ

{
  "ok": true,
  "query": "+77083706944",
  "type": "phone",
  "records_count": 3,
  "sources": ["BigBase", "Jitler"],
  "fio": "Иванов Иван Иванович",
  "age": 42,
  "operator": "АЛТЕЛ",
  "country": "Казахстан",
  "billing": {
    "charged_rub": "1.00 ₽",
    "balance_rub": "549.00 ₽"
  }
}
